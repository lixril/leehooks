## What it does

`useSmartQuery` wraps an async fetch function, caches results in a global in-memory LRU cache, and integrates with React 19 Suspense via `use()`. It also supports deduping, conditional fetching, reactive refetching via `deps`, and optimistic updates with `mutate()`.

## Usage

```tsx
import { Suspense } from "react";
import { useSmartQuery } from "@lixril/leehooks/smart-query";

function Users() {
  const { data } = useSmartQuery("users", () =>
    fetch("/api/users").then((r) => r.json()),
  );

  return <pre>{JSON.stringify(data, null, 2)}</pre>;
}

export default function Page() {
  return (
    <Suspense fallback="Loading...">
      <Users />
    </Suspense>
  );
}
```

## Parameters

### Core Inputs

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string \| readonly unknown[]` | — | Cache key (string or array). Arrays are JSON‑serialized. |
| `fetchFn` | `() => Promise<T>` | — | Async function that returns data (or a `Response`). |
| `options.staleTime` | `number` | `Infinity` | How long (ms) cached data stays fresh before refetching. |
| `options.deps` | `readonly unknown[]` | `[]` | When any value changes, the query refetches. |
| `options.enabled` | `boolean` | `true` | Skip fetching entirely when `false`. |
| `options.dedupingInterval` | `number` | `2000` | Suppress duplicate requests for the same key (ms). |
| `options.onSuccess` | `(data: T) => void` | — | Called once after a successful fetch. |
| `options.onError` | `(error: E) => void` | — | Called after a failed fetch. |

## Returns

### Hook Result

| Name | Type | Description |
| --- | --- | --- |
| `data` | `T` | Resolved data from `fetchFn` (Suspense will wait for it). |
| `refetch` | `() => void` | Invalidates the cache for this key and fetches again. |
| `mutate` | `(updater: T \| (prev: T) => T) => void` | Optimistically update cached data. |

## Notes

### Requirements

`useSmartQuery` uses `use()` under the hood, so it must be rendered inside a `Suspense` boundary and in React 19+.

### Related APIs

#### useSmartQueryClient

Hook wrapper around the shared client. Use inside components to imperatively manage the cache (invalidate, prefetch, read).

```tsx
import { useSmartQueryClient } from "@lixril/leehooks";

function RefreshUsersButton() {
  const client = useSmartQueryClient();
  return (
    <button onClick={() => client.invalidate("users")}>
      Refresh users
    </button>
  );
}
```

#### smartQueryClient

Singleton client for non-React code (route loaders, actions, event handlers). Use it to warm or clear cache outside React.

```tsx
import { smartQueryClient } from "@lixril/leehooks";

await smartQueryClient.prefetch("users", () =>
  fetch("/api/users").then((r) => r.json()),
);
```

#### Client Methods

| Name | Type | Description |
| --- | --- | --- |
| `invalidate` | `(key: QueryKey) => void` | Evict a key so the next render refetches it. |
| `peek` | `<T>(key: QueryKey) => T \| undefined` | Read cached data immediately without suspending. |
| `prefetch` | `<T>(key, fetchFn, options?) => Promise<T>` | Fetch and cache data ahead of time. |
| `clear` | `() => void` | Remove all cached entries. |
