## What is Leehooks?

Leehooks is a small React 19 hook library focused on practical, well-typed utilities for real apps. It extends React's built-in hooks with
state helpers, storage sync, and Suspense-friendly data fetching tuned for React 19 features like `use()`.

<img alt="leehooks" src="https://github.com/user-attachments/assets/8122999c-d513-4a25-9ead-400d699293d7" className="rounded-lg" />

If you regularly reach for custom hooks, Leehooks saves time with ready-to-use building blocks that are easy to read, easy to ship, and easy to extend.
